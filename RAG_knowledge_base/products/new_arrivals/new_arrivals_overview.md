# Nari18 New Arrivals Overview

## Overview

Nari18's **New Arrivals** collection is the section of the website used to showcase recently added and freshly curated unstitched suit sets.

The Nari18 homepage describes this section as:

**"New Arrivals — Freshly Curated Unstitched Suit Sets"**

It highlights the latest handcrafted fabrics and colours for the modern Indian wardrobe, with custom stitching available on many products. Each product page provides product-specific information such as colour variants, pricing, and availability.

New Arrivals should therefore be treated as a **dynamic collection**, rather than a permanent list of specific products. Products can be added, removed, sold out, repriced, or moved into other catalog collections over time.

The New Arrivals section can contain newly introduced Nari18 suit designs across different fabrics, colours, embroidery styles, prints, and occasions.

Nari18's main catalog currently supports filtering by these and other fabric categories, demonstrating that New Arrivals can draw from the broader product range.

## New Arrivals vs Best Sellers

New Arrivals and Best Sellers represent different customer-shopping purposes.

### New Arrivals

Focus on **newly introduced or freshly curated products**.

### Best Sellers

A New Arrivals product should not automatically be described as a bestseller, and a bestseller should not automatically be described as a new arrival.

These classifications should only be used when the current Nari18 website identifies the product accordingly.
