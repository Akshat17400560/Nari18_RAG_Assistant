# Nari18 Order Cancellation Policy

## 1. Overview

Nari18 allows customers to cancel domestic orders only while the order is still pending shipment. Once an order has been shipped or dispatched, it cannot be cancelled through the normal cancellation process.

The current Nari18 Terms & Conditions state that cancellation requests must be sent by email to **info@nari18.com**. If the cancellation is requested before shipment, Nari18 states that the **entire order amount will be refunded**. Once an order has been dispatched, shipping charges are non-refundable.


## 2. When Can an Order Be Cancelled?

### Cancellation is allowed before shipment

A domestic Nari18 order can be cancelled **only before it is shipped**.

The cancellation window therefore depends on the actual fulfilment status of the order rather than simply the time elapsed since purchase.

For example:

- Order placed but not shipped → cancellation may be requested.
- Order being prepared but not yet shipped → contact Nari18 immediately and request cancellation.
- Order already shipped/dispatched → normal cancellation is no longer available.
- Order already delivered → use the applicable return/exchange policy instead of the cancellation policy.

Nari18's Terms explicitly state that orders can be cancelled only before shipment.


## 3. How to Request Cancellation

Customers should request cancellation by contacting Nari18 through the email address specified in the Terms & Conditions:

**Email:** info@nari18.com

The request should ideally include:

- Customer name
- Order number
- Registered phone number or email
- Date of order
- Reason for cancellation, if desired
- Clear request to cancel the order

Because shipment status can change after an order is placed, customers should contact Nari18 as soon as they decide to cancel.

The official Terms specifically instruct customers to email Nari18 for cancellation requests.


## 4. What Happens After a Cancellation Request?

A cancellation request is dependent on the order's shipment status.

### If the order has not shipped

If Nari18 receives and accepts the cancellation before the order is shipped, the Terms state that the **entire order amount will be refunded**.

### If the order has already shipped

Once the order has been dispatched, the order can no longer be cancelled under the normal cancellation policy.

Nari18's Terms specifically state that shipping charges are non-refundable once the order has been dispatched.

If the customer no longer wants the shipped product, the applicable return policy should be checked instead.


## 5. Cancellation vs Return vs Exchange

These are separate processes and should not be treated as interchangeable.

| Situation | Applicable process |
| Order has not shipped | Order cancellation |
| Order has already shipped | Cancellation is no longer available; check return policy |
| Product has been delivered and customer wants to return it | Return policy |
| Product has a qualifying manufacturing defect | Defect exchange policy |
| Customer wants to exchange an eligible product | Exchange policy |
| Product was custom stitched | Custom-stitching restrictions apply |

Nari18's current Terms provide separate sections for cancellation, returns, and exchanges.


## 6. Refund After Cancellation

For a cancellation made before shipment, Nari18's Terms state:

> The entire order amount will be refunded.

This means the cancellation refund is different from the standard return process.

For a standard approved return, Nari18's Terms currently state that the product value is added to the customer's Nari18 store credit/wallet after the returned item passes quality inspection.

Therefore, the RAG system should not incorrectly answer that every cancellation results in store credit. The current cancellation section specifically states that a pre-shipment cancellation receives a refund of the entire order amount.


## 7. Cancellation After Dispatch

Once an order has been dispatched:

- The order cannot be cancelled under the normal cancellation policy.
- Shipping charges are non-refundable.
- If the customer wants to pursue a return after delivery, the separate return policy must be checked.
- Return eligibility may depend on product type and condition.

Nari18's Terms currently state that customised products, sarees with fall/edging, and sale items are non-returnable.


## 8. Custom-Stitched Orders

Custom stitching should be treated carefully because Nari18 has a separate policy for customised products.

Nari18's current Promise states that custom-stitched orders are made-to-measure and are **not eligible for exchange**.

The Terms also state that customised products cannot be returned or exchanged.

For cancellation specifically, the current Terms do not publish a separate cancellation window exclusively for custom-stitched orders. Therefore:

- Do not automatically assume that a custom-stitching order can always be cancelled.
- The key cancellation condition remains whether the order has shipped.
- If stitching or tailoring work has already started, the customer should contact Nari18 immediately for order-specific guidance.
- Do not promise cancellation or refund for a customised order without confirmation from Nari18.


## 9. Sale and Discounted Orders

Nari18's Terms state that products bought during a sale are **non-refundable and non-exchangeable**.

This should not automatically be interpreted as meaning that a pre-shipment cancellation is impossible, because the Terms contain a separate cancellation section stating that orders can be cancelled before shipment and that the entire order amount is refunded when cancelled before shipping.

For a sale order where cancellation is requested, the safest response is:

1. Check whether the order has shipped.
2. If it has not shipped, contact Nari18 immediately through the official cancellation channel.
3. Follow the order-specific decision provided by Nari18.


## 10. Order Modifications

Nari18's current Terms contain a separate instruction for order modifications:

**For modifications, customers should email info@nari18.com within 2 hours of placing the order.**

This is important because an order modification is different from an order cancellation.

Examples of modifications may include correcting information or requesting an order-related change before fulfilment. The Terms do not provide a comprehensive list of all changes that can be made.

For any modification request, customers should contact Nari18 as soon as possible.


## 11. Recommended Cancellation Workflow

For a customer who wants to cancel an order:

### Step 1 — Locate the order details

Keep the order number and customer contact information available.

### Step 2 — Check whether the order has shipped

The cancellation policy applies only before shipment.

### Step 3 — Contact Nari18 immediately

Send the cancellation request to:

**info@nari18.com**

### Step 4 — Include order information

Provide:

- Order number
- Customer name
- Registered contact details
- Cancellation request

### Step 5 — Wait for confirmation

Do not assume that sending an email automatically means the order has been cancelled. The order's shipment/fulfilment status needs to be confirmed.

### Step 6 — If already shipped

Cancellation is no longer available under the normal cancellation policy. After delivery, check whether the order qualifies for Nari18's separate return or exchange policy.


## 12. Important Difference: Cancellation and Return

### Cancellation

Cancellation happens **before shipment**.

According to the current Terms:

- Allowed only before shipment.
- Request through email.
- Entire order amount is refunded if cancelled before shipping.
- Once dispatched, shipping charges are non-refundable.

### Return

Return happens **after the customer has received the order**.

Nari18 currently states that return requests must be raised within 7 days of receiving the order through **My Orders → Return / Exchange**. Approved returns are handled through reverse pickup, followed by quality checking and store-credit processing according to the Terms.
