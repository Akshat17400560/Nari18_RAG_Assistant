# Nari18 Return Policy

## 1. Overview

Nari18 provides a return process for eligible products, subject to the conditions and timelines stated in its current Terms & Conditions.

The current Nari18 Terms state that:

- A return request must be raised **within 7 days of receiving the order**.
- The request is initiated through **My Orders → Return / Exchange** on the Nari18 website.
- Damaged products or tampered packaging should be reported with photos within the same 7-day period.
- Once a return is approved, Nari18 arranges a **free reverse pickup** through Shiprocket.
- The customer does not need to self-ship an approved return.
- After the returned product is received and passes Nari18's quality check, the **product value is added to Nari18 store credit/wallet**.
- Store credit can be used for future Nari18 purchases but cannot be withdrawn to a bank account or UPI.
- Customised products, sarees with fall/edging, and sale items are currently listed as non-returnable.

The current **Our Promise** page separately highlights a 7-day exchange process specifically for manufacturing defects and states that custom-stitched orders are not eligible for exchange.

# 2. Return Request Timeline

The return request must be raised within:

**7 days of receiving the order.**

The 7-day period is important because Nari18's Terms state that requests raised after the specified timeline will not be accepted.


# 3. Where to Raise a Return Request

Nari18's current Terms instruct customers to raise the request through:

**My Orders → Return / Exchange**

on the Nari18 website.

The customer should use the order associated with the product they want to return and follow the available return/exchange workflow.


# 4. Basic Return Process

The current Nari18 return process can be understood as:

1. Receive the order.
2. Inspect the product promptly.
3. Check whether the product is eligible for return.
4. Keep the product unused and unwashed.
5. Keep original tags and packaging intact.
6. Raise the return request within 7 days.
7. Use **My Orders → Return / Exchange**.
8. Provide the required information.
9. Upload photographs where required, especially for damage or packaging issues.
10. Wait for Nari18's approval.
11. Nari18 arranges reverse pickup through Shiprocket if the return is approved.
12. The returned product is received by Nari18.
13. Nari18 performs a quality check.
14. After approval, the eligible product value is added to Nari18 store credit/wallet.


# 5. Return Eligibility

An eligible return must satisfy Nari18's current return conditions.

The Terms specifically state that items must be:

- **Unused**
- **Unwashed**
- In their **original packaging**
- With **original tags intact**

These conditions are intended to ensure that returned garments remain suitable for quality inspection and resale where applicable.


# 6. Product Must Be Unused

Customers should inspect the product without wearing it for extended use.

A product should not be returned after:

- Wearing it
- Washing it
- Altering it
- Stitching it
- Damaging it
- Removing important tags
- Discarding original packaging

unless Nari18 specifically confirms otherwise.


# 7. Product Must Be Unwashed

Nari18's Terms specifically require returned items to be **unwashed**.

Customers should therefore inspect:

- Fabric
- Colour
- Design
- Embroidery
- Size, where applicable
- Product condition

before washing or laundering the product.

### Important

Once a product has been washed, it may no longer satisfy the return conditions.


# 8. Original Tags and Packaging

The current Terms require:

- Original tags intact
- Original packaging intact

for eligible return/exchange requests.

Customers should therefore retain all packaging until they have confirmed that they want to keep the product.

### Recommended customer practice

After delivery:

1. Open the package carefully.
2. Keep the packaging.
3. Keep all tags.
4. Inspect the product.
5. Photograph any suspected defect.
6. Decide whether a return or exchange request is necessary.


# 9. Damaged Product

Nari18 specifically addresses damaged products.

If a customer receives a damaged product, the customer should raise the request **within the same 7-day window** and provide photographs.

The customer should document the issue clearly.

Useful photographs can include:

- Full product
- Close-up of the damaged area
- Packaging
- Shipping package
- Product tag
- Any visible defect

The final eligibility is determined by Nari18 after reviewing the submitted information.


# 10. Tampered Packaging

Nari18's Terms also instruct customers to report **tampered packaging** within the 7-day window and provide photos.

If packaging appears damaged or tampered with on delivery:

1. Photograph the package before discarding it.
2. Photograph the visible issue.
3. Keep the packaging.
4. Raise the request within 7 days.
5. Submit the requested evidence through the return/exchange process.


# 11. Reverse Pickup

Once an eligible return is approved, Nari18 states that a **free reverse pickup** is arranged through Shiprocket.

The customer does not normally need to arrange and pay for self-shipping for an approved return.


# 12. Return Quality Check

After reverse pickup, the returned product is received by Nari18.

The Terms state that the product must pass Nari18's **quality check** before the product value is added to store credit.

The quality check can be understood as verification of the return condition, including compliance with the applicable return requirements.


# 13. Return Refund Method

Nari18's current Terms state that after an approved return passes the quality check:

**The product value is added to Nari18 store credit/wallet.**

This means the current return process should **not be described as an automatic cash refund to the original payment method**.

### Important

The store credit:

- Can be used toward future Nari18 orders.
- Cannot be withdrawn to a bank account.
- Cannot be withdrawn to UPI.


# 14. Store Credit

Nari18's return policy currently uses store credit as the return-value mechanism.

After the approved returned product passes quality inspection:

**Product value → Nari18 store credit/wallet**

The credit can then be used for a future Nari18 purchase.


# 15. Non-Returnable Customised Products

Nari18's current Terms explicitly state:

**Customised products are non-returnable.**

The Our Promise page also states that custom-stitched orders are not eligible for exchange.

This is particularly important for customers who purchase an unstitched suit and then request custom tailoring.


# 16. Sarees With Fall and Edging

Nari18's Terms specifically exclude:

**Sarees with fall and edging**

from returns.

Therefore, the general 7-day return window should not be interpreted as applying to these sarees.


# 17. Sale Items

Nari18's current Terms state that:

**Sale items are non-returnable.**

The Important Notes section further states that products bought during sale are **non-refundable and non-exchangeable**.



# 18. Sale Price vs Sale Item

A product may display a reduced price or discount percentage.

However, the assistant should be careful when determining whether the item qualifies as a **sale item** under Nari18's policy.

Do not automatically infer the legal return classification solely from a percentage shown on a product card.

If the customer asks whether a specific discounted product can be returned, check the current product/checkout policy or advise confirming with Nari18.


# 19. Return vs Manufacturing Defect

Nari18's website distinguishes between its general return terms and its manufacturing-defect exchange promise.

### General return

The Terms provide a 7-day return request process for eligible products, with approved return value issued as store credit after quality checking.

### Manufacturing defect

The Our Promise page specifically states that exchange requests for manufacturing defects are accepted within 7 days, with clear photos/videos required for verification.


# 20. Manufacturing Defect Reporting

If the customer believes the product has a manufacturing defect:

1. Identify the defect.
2. Take clear photographs.
3. Take a video if useful.
4. Raise the request within 7 days.
5. Submit the evidence.
6. Wait for Nari18's verification.
7. Follow the exchange/return instructions provided after approval.

Nari18's Our Promise specifically asks customers to provide clear photos/videos so the team can verify the issue.


# 21. What Counts as a Manufacturing Defect?

The current Our Promise page refers specifically to **manufacturing defects**, but does not provide a complete public list of every possible defect.

Therefore, the assistant should not create an exhaustive defect list as if it were an official Nari18 definition.

Possible examples may include a genuine manufacturing issue, but final classification should be made by Nari18.


# 23. Custom Stitching and Returns

Custom stitching is especially important for Nari18 because many unstitched products can be tailored.

Customers should understand:

**Unstitched purchase + custom stitching = customised product**

and customised products are currently excluded from returns under Nari18's Terms.

The current Our Promise page similarly states that custom-stitched orders are not eligible for exchange.

### Customer guidance

Before requesting custom stitching, customers should confirm:

- Measurements
- Silhouette
- Neckline
- Sleeve style
- Length
- Fit preference
- Lining/finishing requirements

This reduces the risk of an unsuitable customised order.


# 24. Return Eligibility Checklist

Before submitting a return, verify:

- [ ] Request is within 7 days of receiving the order.
- [ ] Product is unused.
- [ ] Product is unwashed.
- [ ] Original tags are intact.
- [ ] Original packaging is intact.
- [ ] Product is not customised.
- [ ] Product is not a sale item where the sale exclusion applies.
- [ ] Product is not a saree with fall/edging.
- [ ] Damage/tampering has been photographed where applicable.
- [ ] The request is submitted through My Orders → Return / Exchange.

These conditions are based on Nari18's current Terms.


# 25. What Customers Should Do Immediately After Delivery

For the safest return experience:

### Step 1 — Inspect

Check the product as soon as possible.

### Step 2 — Photograph

If there is a visible issue, photograph it clearly.

### Step 3 — Preserve packaging

Keep:

- Tags
- Packaging
- Product materials
- Shipping packaging where relevant

### Step 4 — Do not wash

Do not wash the product before resolving a potential return.

### Step 5 — Do not alter

Do not stitch, cut, modify or otherwise alter the product if a return may be required.

### Step 6 — Raise the request

Submit the return/exchange request within the 7-day period.


# 26. Self-Shipping

For an approved return, Nari18's current Terms state that a free reverse pickup is arranged through Shiprocket and that self-shipping is not required.


# 27. Return Pickup

Once the return is approved:

1. Nari18 arranges the reverse pickup.
2. Shiprocket is used for the reverse pickup.
3. The product is collected from the delivery address.
4. The product reaches Nari18.
5. Nari18 conducts the applicable quality check.
6. Eligible product value is added to store credit.

The customer should package the product appropriately and keep the required original packaging and tags intact.


# 28. Return Request Does Not Guarantee Approval

Submitting a request within 7 days does not mean every request will automatically be accepted.

Nari18's policy contains eligibility conditions and requires a quality check after the returned product is received.


# 29. Return Value

The current Terms refer to the **product value** being added to Nari18 store credit after the approved return passes quality inspection.

Do not promise additional amounts unless the current policy specifically confirms them.

In particular, do not automatically promise:

- Shipping reimbursement
- Payment-gateway charges
- Tailoring charges
- Other service charges

unless Nari18's current policy specifically states that they are refundable.

# 30. Store Credit Restrictions

Current Nari18 Terms state:

- Store credit can be used toward future Nari18 orders.
- Store credit cannot be withdrawn to a bank account.
- Store credit cannot be withdrawn to UPI.


# 31. Return Policy and Payment Method

The customer's original payment method does not automatically change the return mechanism.

For eligible returns, the current Terms state that the product value is added to Nari18 store credit after quality approval.

Therefore, do not tell customers that:

- UPI payment automatically means UPI refund.
- Card payment automatically means card refund.
- COD automatically means cash refund.

The current standard return mechanism is Nari18 store credit.


# 32. Return Policy and COD Orders

COD is a payment method and should not be confused with the return process.

If an eligible COD order is returned, the customer should follow the current Nari18 return process.

The Terms state that approved return value is added to Nari18 store credit rather than describing a cash refund to the customer.


# 33. Return Policy and Prepaid Orders

For prepaid orders, the customer should also follow the same eligibility and timeline requirements.

The fact that an order was paid online does not automatically create a bank/card/UPI refund under the current standard return policy.

For an eligible approved return, the current Terms specify Nari18 store credit.


# 34. Return Policy and Shipping

Nari18's current Terms separately state shipping and return policies.

The return policy should therefore not be confused with the shipping policy.

Current Terms state that domestic orders are delivered within 5–6 working days unless otherwise specified in product details, while return requests must be raised within 7 days of receiving the order.

For return questions, use the return timeline rather than the delivery timeline.


# 35. Return Policy and Product Condition

The condition of the product is critical.

The current Terms require returned items to be:

**Unused + unwashed + original packaging + original tags intact.**

This should be one of the first checks when answering a return question.


# 36. Return Policy and Alterations

Customers should not alter a product before determining whether they want to return it.

Examples include:

- Stitching
- Cutting
- Hemming
- Adding lining
- Changing neckline
- Changing sleeves
- Altering length
- Embroidery modifications

Customised products are excluded from returns under the current Terms.


# 37. Return Policy for Unstitched Suits

For an unstitched suit, customers should inspect the fabric and components before:

- Cutting
- Stitching
- Washing
- Altering
- Customising

Once the product becomes customised, the customised-product exclusion applies under the current Terms.


# 38. Return Policy for Stitched Products

Stitched products should be treated according to their current product and order status.

If the product is a standard stitched product and is otherwise eligible, the general return conditions may apply unless it falls under an exclusion.

If it was customised or made-to-measure, the customised-product exclusion applies.


# 39. Return Policy for Sale Products

The current Terms explicitly state:

**Products bought during sale are non-refundable and non-exchangeable.**

Therefore, customers purchasing products under sale conditions should review the applicable terms before placing the order.


# 40. Return Policy for Damaged Packages

If the package appears tampered with or the product arrives damaged:

1. Take photographs immediately.
2. Preserve the packaging.
3. Raise the request within 7 days.
4. Submit the photos through the return/exchange workflow.
5. Wait for Nari18's verification and instructions.

This is specifically covered in the current Terms.
